# 報告目錄

本目錄存放生命周期預測與歷史驗證輸出。

## 目前產物

| 檔案 | 說明 |
| --- | --- |
| sample_lifecycle_scored.csv | 使用合成行情資料產出的每日生命周期分數 |
| sample_backtest_report.json | 使用合成行情資料產出的機器可讀驗證報告 |
| sample_backtest_report.md | 使用合成行情資料產出的人工可讀驗證報告 |

## 注意

`sample_*` 檔案只用來驗證資料處理、預測、回測與報告流程可以正常執行，不代表模型已通過真實市場歷史驗證。

真實驗證需改用台股加權指數、櫃買指數、S&P 500、NASDAQ 或其他指定市場的歷史資料，並確認資料期間包含多頭、空頭與盤整階段。
