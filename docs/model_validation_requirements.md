# 大盤走勢預測與歷史驗證需求

## 功能目標

本專題最終功能必須達到：

- 判斷目前大盤生命周期階段。
- 預測未來大盤走勢方向與風險狀態。
- 用歷史資料做 walk-forward 驗證。
- 輸出可追蹤的績效指標，不能只靠主觀圖形判斷。

## 預測輸出

每次模型更新後，至少輸出下列欄位：

| 欄位 | 說明 |
| --- | --- |
| lifecycle_stage | 目前生命周期階段 |
| stage_score | 階段總分 |
| trend_score | 趨勢分數 |
| momentum_score | 動能分數 |
| volatility_score | 波動分數 |
| risk_regime | risk_on、neutral、risk_off |
| forward_1w_view | 未來 1 週看法 |
| forward_4w_view | 未來 4 週看法 |
| confidence | 信心分數 |

## 驗證原則

### 禁止偷看未來

- 所有特徵只能使用當日以前已知資料。
- 預測第 T 日之後走勢時，不可使用 T 日之後的價格、成交量或標籤。
- 回測訊號必須至少延遲一根 K 棒執行。

### Walk-forward 驗證

採用滾動式驗證：

1. 使用早期資料建立規則或訓練模型。
2. 在下一段未看過的資料上驗證。
3. 往後移動視窗。
4. 合併所有 out-of-sample 結果。

### 驗證指標

| 指標 | 說明 |
| --- | --- |
| direction_accuracy | 預測方向命中率 |
| balanced_accuracy | 多空樣本不均衡時的平衡準確率 |
| max_drawdown | 策略最大回撤 |
| annual_return | 年化報酬 |
| sharpe_ratio | 風險調整後報酬 |
| risk_off_recall | 是否能抓到高風險下跌期 |
| false_alarm_rate | 錯誤警報率 |

## 通過標準

初版 baseline 不要求完美，但必須通過基本門檻才視為可用：

- out-of-sample 方向命中率高於 50%。
- 風險關閉訊號能降低最大回撤。
- 不能只在單一多頭年份有效。
- 至少覆蓋一段多頭、一段空頭、一段盤整期。
- 每次驗證都能重現，不靠人工挑選區間。

## 模型分層

### 第一層：規則式生命周期模型

用途：

- 建立可解釋 baseline。
- 對每個時間點產生階段、分數、風險狀態。
- 作為後續機器學習模型的比較基準。

### 第二層：統計或機器學習模型

候選：

- Logistic Regression
- Random Forest
- XGBoost
- Hidden Markov Model

用途：

- 預測未來 1 週與 4 週方向。
- 預測是否進入 risk_off。
- 與規則式 baseline 比較。

### 第三層：歷史相似情境

用途：

- 找出目前狀態和歷史哪些區間相似。
- 比較相似區間後續報酬、回撤與勝率。
- 作為模型輸出的解釋輔助，不單獨作為交易依據。

## 報告要求

每次跑完歷史驗證，需輸出：

- 驗證期間
- 資料筆數
- 預測命中率
- 多空分段績效
- 最大回撤
- 風險關閉效果
- 最差年份
- 模型失效情境

## 單日預測驗證

除整段歷史回測外，系統也必須支援指定日期驗證：

1. 輸入指定日期。
2. 取該日或之前最近交易日的大盤資料。
3. 輸出當日生命周期階段、風險狀態與預測方向。
4. 往後看指定交易天數的真實收盤價。
5. 比較預測方向與實際方向。

單日驗證輸出欄位：

| 欄位 | 說明 |
| --- | --- |
| requested_date | 使用者輸入日期 |
| signal_date | 實際使用訊號日期 |
| validation_date | 驗證日期 |
| input_close | 訊號日收盤指數 |
| future_close | 驗證日收盤指數 |
| future_return | 後續實際報酬 |
| predicted_direction | 模型預測方向 |
| actual_direction | 實際方向 |
| is_hit | 是否命中 |
