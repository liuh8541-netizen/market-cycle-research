# 大跌後反彈失敗：正確做法

## 研究問題

情境：

1. 今天大跌，例如跌 1000 點或跌幅超過 3%。
2. 隔天大反彈。
3. 但後面又繼續大跌。

要判斷這種狀況，不能只看「隔天有沒有反彈」，而要看反彈是否修復市場結構。

## 核心觀念

大跌後的反彈分兩種：

- 有效反轉：反彈修復趨勢、量能、籌碼與市場廣度。
- 反彈失敗：反彈只是技術性回補，沒有修復結構。

預測重點是辨識第二種。

## 第一版價格規則

先用價格資料定義：

1. 第 0 日大跌：單日跌幅小於等於 -3%。
2. 第 1 日反彈：單日漲幅大於等於 +1%。
3. 反彈日仍未站回 20 日或 60 日均線。
4. 反彈日量能低於大跌日，或反彈日沒有收復大跌日實體一半。

若同時成立，標記為：

```text
failed_rebound_after_crash
```

## 驗證方式

對所有歷史事件統計：

- 反彈後 5 日是否下跌
- 反彈後 20 日是否下跌
- 平均報酬
- 中位報酬
- 下跌機率

## 下一版應加入的非價格資料

價格規則只是 baseline。要提高準確度，需要加入：

- 外資是否持續賣超
- 融資是否仍未出清
- 期貨法人是否仍偏空
- Put/Call 是否仍偏避險
- VIX 是否未回落
- 上漲家數是否沒有擴散
- 成分股站上均線比例是否仍低

## 成功標準

若要作為可用預報，需達到：

- 下跌機率大於 80% 作為初步有效。
- 下跌機率大於 90% 才符合高確定性特殊情境。
- 樣本數至少 50 筆。
- Walk-forward 仍能維持高命中。
