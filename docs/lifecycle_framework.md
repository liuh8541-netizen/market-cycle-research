# 生命周期框架

## 六階段定義

| 階段 | 名稱 | 核心特徵 |
| --- | --- | --- |
| 1 | 築底期 | 跌勢放緩，低點不再明顯破底，廣度或動能開始改善 |
| 2 | 初升期 | 價格重新站回中期均線，族群擴散，風險偏好回升 |
| 3 | 主升期 | 趨勢與廣度同步向上，回檔有限，資金輪動健康 |
| 4 | 高檔震盪期 | 指數仍強但內部結構轉弱，背離增加 |
| 5 | 初跌期 | 關鍵支撐跌破，反彈失敗，波動放大 |
| 6 | 主跌期 | 均線空頭排列，廣度惡化，風險資產同步承壓 |

## 判斷維度

### 趨勢

- 收盤價與 20、60、120、240 日均線的相對位置
- 均線斜率
- 高點與低點結構

### 動能

- RSI 是否維持強勢區或弱勢區
- MACD 是否擴張或收斂
- 上漲日與下跌日的力道差異

### 波動

- 波動率是否放大
- ATR 是否擴張
- 大跌日是否集中出現

### 廣度

- 上漲家數是否擴散
- 成分股高於均線比例是否改善
- 創新高與創新低家數是否背離

### 資金

- 成交值是否支持突破
- 法人買賣超是否一致
- 融資是否過熱或斷頭

## 階段轉換觀察

| 從 | 到 | 常見訊號 |
| --- | --- | --- |
| 築底期 | 初升期 | 價格站上 60 日線，廣度改善，低點墊高 |
| 初升期 | 主升期 | 均線多頭排列，突破後回測不破，成交擴大 |
| 主升期 | 高檔震盪期 | 指數創高但廣度不再創高，動能背離 |
| 高檔震盪期 | 初跌期 | 跌破中期均線，反彈量縮，類股輪動失序 |
| 初跌期 | 主跌期 | 反彈不過壓力，低點續破，波動上升 |
| 主跌期 | 築底期 | 跌幅收斂，恐慌釋放，內部指標領先改善 |
