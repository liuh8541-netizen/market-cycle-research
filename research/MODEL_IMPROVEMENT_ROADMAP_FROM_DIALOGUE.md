# 對談累積觀察轉模型改善路線圖

更新日：2026-09-11

本文件把使用者與模型長期對談中逐步形成的市場觀察，整理成可執行、可驗證、可跨電腦接續的模型改善手段。原則是：保留人性、八卦、兵法、心律、病歷與氣象雷達的觀念，但全部落到資料欄位、分數、條件、驗證與失效規則。

## 核心總綱

模型不是每天重猜一次漲跌，而是每日追蹤同一個生命週期劇本是否仍成立。

| 對談觀念 | 模型語言 | 目的 |
| --- | --- | --- |
| 股市有生命，像心跳 | 市場心律監控 | 判斷漲跌是否仍屬健康呼吸 |
| 夜盤是前哨，日盤是裁判 | 日夜盤雙層驗證 | 防止把夜盤直接當日盤答案 |
| 約兩週一次大波動 | 雙週換檔候選 | 追蹤階梯式緩升/緩降與大波動節奏 |
| 本週壓洗、下週修復 | 劇本檢查表 | 用收盤結果保留、降權或改寫劇本 |
| 攻 47,000 未站穩 | 關卡攻防病歷 | 記錄攻堅、退守、延長賽與再攻條件 |
| 資料是意圖表現 | 意圖痕跡解碼 | 把價格、量、期現差、新聞轉成戰術訊號 |
| 兵法、八卦、五行是人性語言 | 中層心理戰框架 | 用來分類，不取代資料驗證 |
| 每次錯誤都找為什麼 | 誤差病歷與自主修正 | 防止同類錯誤重複發生 |

## 一、劇本不是答案，是檢查表

### 對談結論

使用者強調：觀察「本週收低、下週緩升」不是斷言今天一定如此，而是依照過去劇本建立觀察框架。模型不得把劇本當成命令或預言。

### 改善手段

每日報告要把劇本拆成四段：

| 項目 | 說明 |
| --- | --- |
| 原劇本 | 盤前或前一日形成的預期路徑，例如壓洗、攻關、延長賽、修復 |
| 今日驗證 | 用開盤、低點、收盤、量能、族群、期現差核對是否吻合 |
| 劇本處置 | 保留、降權、改寫、失效 |
| 次日條件 | 下一日只看哪些關鍵線與訊號，不重新亂猜 |

### 程式落點

- `reports/today_market_forecast.md` 增加或強化「劇本驗證」段。
- `reports/previous_day_forecast_error_analysis.md` 記錄劇本是否被驗證。
- `reports/market_clinical_ledger.md` 增加劇本狀態欄位。

## 二、階梯式緩升/緩降與雙週換檔

### 對談結論

近月觀察不是每天無序波動，而是：

- 每日有日內上沖下洗。
- 每週有主攻或主殺日。
- 約 8～12 個交易日可能出現一次較大換檔。
- 大波動後若低點墊高，屬緩升；若高點降低、低點下移，屬緩降。

### 改善手段

建立 `biweekly_wave_shift` 候選規律。

| 指標 | 計算方式 | 意義 |
| --- | --- | --- |
| 大波動日 | 單日振幅 >= 1.5% 或收盤漲跌 >= 1.0% | 市場出現換檔壓力 |
| 換檔間隔 | 大波動日之間交易日差 | 是否集中在 8～12 日 |
| 階梯低點 | 近 5 日低點 vs 近 20 日低點 | 判斷緩升或破壞 |
| 階梯高點 | 近 5 日高點 vs 近 20 日高點 | 判斷攻關是否有效 |
| 收盤位置 | 當日 close 在 high-low 區間的位置 | 判斷是收回或收低 |

### 驗證規則

- 若大波動後 3～5 日內低點不破且收盤逐步墊高，標為「換檔後緩升」。
- 若大波動後跌破前低且收不回，標為「換檔後緩降」。
- 若大波動接續大波動，標為「高頻震盪」，方向信心降權。

## 三、關卡攻防病歷

### 對談結論

本週原本應攻 `47,000`，但最後沒有站穩，因此不是突破成功，而是「攻 47,000 未站穩後的高檔回測」。這類關卡攻防要留病歷，不可每天忘記。

### 改善手段

建立 `battlefield_checkpoint_ledger`。

| 欄位 | 例子 |
| --- | --- |
| 關卡 | 46,000 / 46,550 / 47,000 / 48,000 / 50,000 |
| 攻防狀態 | 攻堅、站上、未站穩、退守、延長賽、再攻 |
| 成功條件 | 連續收上、量能支撐、權值股同步、族群廣度擴散 |
| 失敗條件 | 收不回、量縮上攻、長上影、期貨領跌、族群分化 |
| 下一步 | 守線、回測、再攻、退守上一階 |

### 0/1 主劇本

- `1`：關卡通過，進入下一階攻防。
- `0`：關卡未通過，退回上一階重煉。

## 四、夜盤前哨與日盤裁判

### 對談結論

夜盤大跌後，日盤照習慣容易先跌深，但真正答案不是跌本身，而是收盤位置。夜盤只能判前哨壓力，日盤才驗真偽。

### 改善手段

夜盤訊號必須分三基準：

| 基準 | 用途 |
| --- | --- |
| 官方漲跌 | 看市場公告口徑 |
| 夜盤開收到收盤 | 看夜盤內部路徑 |
| 相對前一有效夜盤收盤 | 看夜盤自身連續性 |

日盤驗證必須核對：

- 是否跌破夜盤低點。
- 跌破後 30～60 分鐘是否收回。
- 收盤是否站回夜盤收盤、昨收、短均、整數關卡。
- 權值股與族群廣度是否同步確認。

## 五、資料即意圖痕跡

### 對談結論

資料不是死數字，而是資金意圖留下的表現。但意圖不是結論，必須回到日盤與病歷驗證。

### 改善手段

| 資料 | 意圖候選 | 驗證 |
| --- | --- | --- |
| 夜盤急跌 | 避險、誘空、壓力測試 | 日盤是否跌破收不回 |
| 夜盤急漲 | 預期轉強、誘多、空單回補 | 日盤是否開高走高或開高壓回 |
| 日盤收近高 | 承接成功、多方主導 | 隔日是否續守 |
| 日盤收近低 | 賣壓未解、追價退潮 | 隔日是否再破 |
| 期指領跌 | 避險先行、測壓 | 現貨是否跟跌 |
| 加權領先期指 | 現貨承接較強 | 期貨是否回補 |
| 量縮 | 觀望、等待事件、攻勢不足 | 後續放量方向 |
| 族群分化 | 權值撐盤或內部退潮 | 等權報酬與廣度 |

## 六、心律與健康監控

### 對談結論

市場像心跳。不是天天漲才健康，而是漲跌、換手、收回、低點墊高仍在可控風險內。

### 改善手段

心律分型：

| 分型 | 條件 | 處理 |
| --- | --- | --- |
| 正常心跳 | 漲跌交錯、振幅可控、跌後可修復 | 維持原劇本 |
| 興奮心跳 | 連漲、量能升、追價熱 | 防追高與高檔換手 |
| 沮喪心跳 | 連跌、反彈弱、收低 | 降風險，等止跌 |
| 異常心律 | 連續破線收不回、量價失控 | 升級警戒 |
| 事件心律 | 外部新聞或美股主市場重定價 | 啟動外部事件重置 |

## 七、病灶基因、觸發按鈕與即效藥

### 對談結論

高檔估值、前高套牢、融資、權值股過熱等不是今天突然出現，而是長期病灶；新聞、美股、費半、TSM ADR、VIX、油價、利率、夜盤破線是觸發按鈕。

### 改善手段

每日必須依序輸出：

1. 既有病灶：高檔壓力、族群分化、融資追價、權值過熱。
2. 發病跡象：漲不動、收低、量價背離、期現差擴大。
3. 即效藥：美股/費半/ADR/VIX/利率/匯率/夜盤急變。
4. 日盤結果：收回或收不回。
5. 病歷結論：對症、無效、殘留陰霾、復發、升級。

## 八、孫子兵法與八卦的模型化

### 對談結論

兵法與八卦不是迷信答案，而是人性與週期的分類語言。它們負責提出假設與戰術語境，最後仍由資料驗證。

### 改善手段

| 框架 | 模型用途 |
| --- | --- |
| 震 | 發動、試攻、回測不破 |
| 巽 | 順勢擴散、族群輪動 |
| 離 | 過熱、亮點集中、追價風險 |
| 坤 | 高檔承載、換手、出貨壓力 |
| 兌 | 反彈誘惑、誘多/誘空 |
| 乾 | 極盛攻頂、轉折高風險 |
| 坎 | 深跌、恐慌、流動性陷落 |
| 艮 | 止跌、底部完成、重新出發 |

兵法對應：

| 兵法 | 市場語言 |
| --- | --- |
| 知可戰不可戰 | 關卡未站穩不宣稱突破 |
| 以正合，以奇勝 | 主趨勢為正，夜盤/新聞/壓回為奇 |
| 避實擊虛 | 不硬攻上方重壓，先清浮籌與弱心理 |
| 先求不敗 | 先排除崩盤與破線風險 |
| 兵貴勝不貴久 | 延長賽太久要降權 |

## 九、每日自主修正流程

### 每日收盤後

1. 鎖定今日正式資料，不可回填盤前預測。
2. 比對前一日劇本與今日收盤。
3. 分類錯誤：資料時點錯、夜日盤誤判、外部重置漏判、心理戰過度解讀、族群廣度缺口、關卡條件錯。
4. 寫入病歷與前瞻紀錄。
5. 若是程式 bug，修正程式並跑測試。
6. 若只是研究假設失效，降權，不硬改成新真理。

### 每日盤前

1. 上網核對國際重大財經政治消息。
2. 更新夜盤與外部市場。
3. 套用前一日保留劇本。
4. 輸出今天只需觀察的 0/1 關卡。

## 十一、2026-09-11 盤中戰術案例

本日新增實戰病歷：`research/TACTICAL_CASE_2026-09-11_DETERRENCE_LINE.md`。

模型新增候選語彙：

| 語彙 | 含義 | 驗證 |
| --- | --- | --- |
| 藏線嚇阻，留退伏攻 | 多方不明示真底線，讓空方無法確定壓破表面線是否有效 | 夜盤與下週一是否守住 46,000 並收回日盤收盤附近 |
| 借敵死線，轉己生命 | 空方製造死亡線，若收盤守住，該線反成多方生命線 | 46,000 是否跌破後收回或收盤守住 |
| 太極守線，借空補多 | 多方不強拉，等待空方回補變成買盤 | 期貨不再領跌、期現差收斂、低點不再下移 |
| 敵形已露，我線未明 | 空方攻擊線明顯，多方真底線不明示 | 空方是否反覆攻同線卻無法有效破位 |

本案例用來訓練模型辨識：同一條價格線不是固定支撐或壓力，而是由多空雙方能否把心理意義定義成功來決定。若空方設定的死亡線無法完成收盤破位，該線可能反成空方回補壓力。

## 防呆

- 本文件整理的是模型改善手段，不是投資命令。
- 任何規律只能先列為候選，必須經前瞻驗證。
- 不能把回測結果回填為當時已知。
- 不能宣稱單一主體操控市場，只能描述資金結構與行為痕跡。
- 模型可以越來越像市場聽診器、氣象雷達與戰術沙盤，但仍必須承認隨機觸發與資料缺口。
