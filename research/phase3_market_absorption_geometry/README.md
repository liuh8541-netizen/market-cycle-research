# 第三階段：市場衝擊吸收／放大幾何

狀態：不含方向標籤的歷史資料回補與可行性稽核。

這不是研究公開固定技術公式。未解問題是：同樣的市場壓力，為何有時被全市場承接並反轉，有時同步收在低點附近而繼續放大？

候選因數以每個歷史交易日的逐股價格路徑橫斷面形成：

- 收盤在當日高低區間的位置分布
- 報酬相對當日振幅的單向效率
- 下跌但自低點回收的股票比例
- 上漲但自高點回落的股票比例
- 全市場方向同步性與方向熵
- 收在高／低區域的成交金額占比
- 上下極端行程與橫斷面離散度

所有特徵只描述當日已完成的市場結構，不使用其後大盤方向。

資料來源：FinMind `TaiwanStockPrice`。官方資料自 1994-10-01 起；本專案可對齊的 TWII 歷史自 1997-07-02 起。資料於收盤後更新，只能在下一交易決策時使用。

隔離規則：

- 只寫入 `research/phase3_market_absorption_geometry/`。
- 正式程式與正式資料均唯讀。
- 不研究單一 K 線固定公式，不以已知技術指標作為新結論。
- 回補及因數形成階段不得讀取 20 日後方向標籤。
- 若資料可行，正式確認將保留獨立歷史年代，不以同一資料反覆調參。
