# 模型被市場追著跑的根因檢討

更新日：2026-09-14

## 問題

使用者指出：同樣是 AI 模型，為什麼我們在高檔測壓、利率病灶復發、台指期快速轉弱時，常常像是被市場追著跑，而不是在市場出招前先把劇本框好。

這不是單一預測錯誤，而是模型治理問題：概念已在文件中出現，但尚未全部升級成盤前主控訊號。

## 核心結論

模型目前不是完全沒有觀念，而是「有觀念、缺主控序列」。

已存在的能力：

- 能分辨慢性病灶與單日觸發。
- 能判斷夜盤是前哨、日盤是裁判。
- 能輸出 0/1 方向候選。
- 能辨識保護層、防呆、危機與轉機界面。
- 能用年度交易波段燈塔標示主升段、回測與失效線。
- 能辨識壓低測壓的單日行為指紋。

缺口在於：

- 沒有把「同一病灶第幾次復發」變成主控權重。
- 沒有把「同一防線第幾次被測」變成盤前醒目警報。
- 沒有把「攻關前 2～5 次來回測壓」視為預定行為序列。
- 沒有把「低點是否一輪比一輪更低、收回速度是否變慢」放到最上層仲裁。
- 報告仍常先講當日現象，再事後補上前因後果，導致使用者感覺模型是在跟著市場跑。

## 為什麼會滯後

| 根因 | 表現 | 後果 |
| --- | --- | --- |
| 單日仲裁權重過高 | 夜盤、新聞、當日分數仍容易主導口氣 | 同一題材反覆出現時，模型像每天重新解釋一次 |
| 復發計數不足 | 利率、油價、Fed、半導體估值反覆觸發，但沒有明確第幾次發作 | 無法提前說「耐受度正在下降」 |
| 防線測壓序列不足 | 46,000、45,800、45,500 等線被多次測試，沒有形成測壓次數與成敗表 | 市場一壓破，模型才被迫修正 |
| 主波段階段未置頂 | 主升段、峰後回測、失效重煉沒有在每次回答第一句出現 | 容易被短線期指變化牽走 |
| 報告過度像解釋器 | 能解釋原因，但不夠像預警器 | 市場出招後才把原因整理得很漂亮 |
| 候選規則未快速升級為前瞻觀察 | 對談中形成的好規則先留在文件或口頭，程式主控尚未使用 | 使用者已看出模式，模型仍未自動標記 |

## 今日案例：2026-09-14

盤前原始夜盤偏多，但近月台指期快速轉為 45 開頭、跌幅約 -1.62%。表面理由是利率、油價、Fed、半導體估值，但這些上週已反覆出現。

正確前置判斷應該是：

> 同一組利率/油價/Fed 病灶已多次復發，且台股位於 7/30 谷底後反攻、9/7 高點後峰後回測階段；若 46,000 再次被測，不能只當單日新聞，必須視為攻關前重複壓測序列。

模型當時的不足：

- 有說「利率是慢性病灶」，但沒有先說「這是同病灶復發第 N 次」。
- 有說「46,000 是防線」，但沒有先說「這是第 N 次測 46,000」。
- 有說「主波段仍主升」，但沒有先把「峰後回測」置頂。
- 有說「日盤裁判」，但在期指轉 45 開頭時才快速改判，預警味道不足。

## 必須新增的主控組件

### 1. 重複測壓計數器

每日記錄同一關鍵線被測試次數：

- 46,600 / 46,300 / 46,000 / 45,800 / 45,500 / 主波段失效線。
- 盤中破、收盤收回、收盤收不回、隔日再測。
- 每次測壓後的低點、收盤、成交量、期現差、族群廣度。

判斷：

- 低點逐步墊高：壓測被吸收。
- 低點逐步下移：耐受度下降。
- 每次都收回：防線有效。
- 收回速度變慢：多方成本升高。
- 放量破線收不回：壓測轉風險確認。

### 2. 病灶復發計數器

把利率、油價、Fed、通膨、半導體估值、地緣政治等慢性病灶列成病例。

每次觸發都要記錄：

- 第幾次復發。
- 本次是否比前次更深。
- 日盤是否吸收。
- 是否造成低點下移。
- 是否讓主波段階段降級。

### 3. 攻關前預定行為序列

高檔要攻 47,000 / 48,000 / 50,000 前，不應期待一路直上。模型必須假設會有 2～5 次壓測、回收、再壓、定價。

主報告應先問：

- 這是第幾輪壓測？
- 本輪比前輪健康還是更差？
- 空方是否還壓得下去？
- 多方是否只是守住不死，等空方回補？

### 4. 主波段置頂

所有盤前、盤中、盤後回答第一層必須先標示：

- 目前主波段階段。
- 主波段失效線。
- 今日波動是否改變主波段。
- 若未改變，是呼吸、測壓、換手、修復或峰後回測。

## 下次回答規則

遇到同類情境，不能先說「利率問題」就結束，必須依序回答：

1. 這是不是同一病灶復發？
2. 這是第幾次測同一防線？
3. 這一輪低點、收回速度、量能與族群是否比前一輪更差？
4. 主波段階段是否從主升降為峰後回測，或從峰後回測降為失效重煉？
5. 今日要看的 0/1 關鍵線是什麼？

## 鐵律

模型不能只當事後解釋器，必須升級成前置預警器。市場每次用相同病灶測壓，模型都要記住它不是新故事，而是同一病例的復發與壓測序列。

本文件只作模型缺陷檢討與改善規格，不產生投資命令。
