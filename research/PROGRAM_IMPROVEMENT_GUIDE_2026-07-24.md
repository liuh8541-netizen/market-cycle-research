# 台股研究成果：其他程式精進參考報告

日期：2026-07-24  
用途：提供其他預測、交易、風控及報告程式採用研究結論。  
限制：本報告不構成交易建議，不得把未通過研究改寫成正式訊號。

## 一、可直接採用的核心結論

### 1. 每個模型只服務一個明確目標

開盤方向、開盤缺口幅度、盤中剩餘方向、收盤方向及20交易日方向是不同目標，不可互相替代。

目前只有下列窄目標通過正式驗證：

| 模型 | 合法使用範圍 | 準確率 | 狀態 |
| --- | --- | ---: | --- |
| `canonical_night_spread_gap_v1` | 當日現貨開盤相對前一現貨收盤的方向 | 97.38% | 已驗證 |
| `daily_night_gap_amplitude_v1` | 絕對開盤缺口是否超過因果歷史75分位；不是方向預測 | 92.66% | 已驗證 |

禁止把以上模型用於預測當日收盤、盤中延續或20日方向。

### 2. 廣義多日方向應保持停用

主要多日方向模型及新增因數均未達正式門檻。其他程式不得輸出正式多日方向訊號；研究數值只能標示為 `research_only`。

### 3. 風險分類優先於勉強預測方向

委託簿早盤訊息預測09:15至收盤方向約49.14%，不具實用方向能力；辨識重大剩餘波動風險約78.21%，較適合用於：

- 降低部位；
- 擴大或縮小停損距離；
- 暫停新單；
- 顯示高波動警示；
- 調整執行方式。

78.21%仍未通過正式90%門檻，因此只能作輔助風控，不得標示為已驗證交易訊號。

## 二、新增因數研究的工程結論

| 新增因數 | 案例 | 準確率 | 最強基準 | 決策 |
| --- | ---: | ---: | ---: | --- |
| 月營收市場結構 | 81 | 55.56% | 61.73% | 不採用 |
| 信用放空庫存結構 | 67 | 55.22% | 64.18% | 不採用 |
| 市場衝擊吸收／放大幾何 | 96 | 53.13% | 59.38% | 不採用 |

工程含義：

- 新增資料不等於新增預測力。
- 新模型必須同時勝過價格控制及同日期強簡單基準。
- 未勝過基準的因數不可因具經濟故事而上線。
- 上述實驗已封存，不得改門檻、切子群或微調後重跑。

## 三、建議的下游程式架構

```text
原始資料
  -> 完整性檢查
  -> 時間可得性檢查
  -> 交易日與目標對齊
  -> 目標專用模型
  -> purged walk-forward 驗證
  -> 強基準與控制模型比較
  -> 正式驗證閘門
  -> 正式訊號／研究觀察／風險警示分流
```

### 必備資料欄位

每筆輸入因數建議保存：

- `source_date`：資料描述的來源日期；
- `available_at`：資料實際可被取得的時間；
- `decision_date`：允許首次用於決策的交易日；
- `is_complete`：資料是否已完成；
- `dataset_version`：資料版本或快照識別；
- `data_sha256`：輸入快照雜湊。

任何 `is_complete=false` 或 `available_at` 晚於決策時間的資料均不得送入模型。

## 四、正式驗證閘門

新的正式模型至少必須同時符合：

| 閘門 | 最低要求 |
| --- | ---: |
| 樣本外準確率 | 90% |
| 有效非重疊案例 | 100 |
| 覆蓋率 | 10% |
| Wilson 95%下限 | 80% |
| 重要區段最低準確率 | 80% |
| 強基準比較 | 顯著勝出 |
| 控制模型比較 | 提供顯著增量 |
| 時序要求 | 嚴格因果、purge、非重疊 |

準確率不得脫離案例數、覆蓋率、Wilson下限與分段穩定性單獨呈現。

## 五、建議的訊號輸出契約

```json
{
  "model_id": "canonical_night_spread_gap_v1",
  "target": "same_day_cash_open_vs_prior_cash_close",
  "scope": "cash_open_only",
  "validated": true,
  "enabled": true,
  "signal_class": "formal",
  "formal_signal": 1,
  "research_signal": null,
  "risk_level": null,
  "data_complete": true,
  "decision_date": "YYYY-MM-DD",
  "reason": "validated_scope_limited_model"
}
```

強制規則：

- `validated=false` 時，`formal_signal` 必須是 `null`。
- `enabled=false` 時，不得由前端自行推導多空文字。
- `signal_class=research` 時，畫面必須明示「研究觀察」。
- 幅度風險模型只能輸出風險類別，不得輸出方向。
- 模型目標與請求目標不一致時，必須拒絕產生訊號。

## 六、時間與夜盤語意

- 台北時間05:00前，當日夜盤尚未完成，不可誤標為完整當日訊號。
- 週一訊號必須使用前一個實際交易日晚間開始的夜盤窗口，不可要求不存在的週日夜盤。
- 未完成夜盤、錯誤契約月份或超出OHLC容忍範圍的資料必須拒絕。
- 財務、籌碼或營收資料必須依公告可得時間向後位移，不可只依來源日期合併。

## 七、實驗治理

每個正式研究應保存：

- 唯一 `experiment_id`；
- 鎖定設定檔；
- 輸入快照及SHA-256；
- 開始與完成回條；
- 唯一正式執行狀態；
- 完整案例紀錄；
- 獨立稽核結果；
- 通過或失敗的永久研究帳本。

同一 locked experiment 只准一次正式確認。中斷只能從固定checkpoint確定性續跑，不能重新選參數。

## 八、建議實作優先順序

1. 在所有下游程式加入目標範圍檢查。
2. 未驗證模型的 `formal_signal` 統一改為 `null`。
3. 加入 `available_at`、`decision_date` 與 `is_complete`。
4. 將方向模型與風險模型拆成不同介面。
5. 加入強基準、控制模型、Wilson下限及非重疊案例閘門。
6. 為每次正式研究建立不可變回條與獨立稽核。
7. 將失敗研究加入永久去重索引，防止換名重試。

## 九、最終決策摘要

- 可正式使用：限定範圍的開盤缺口方向模型。
- 可正式使用：限定範圍的開盤缺口幅度風險模型。
- 僅可輔助風控：尚未通過90%門檻的微結構風險資訊。
- 必須停用：廣義多日方向正式訊號。
- 不得採用：月營收、信用放空庫存及市場吸收幾何的既有鎖定版本。
- 未來新研究必須使用真正新因數與獨立確認樣本，不得從已失敗結果事後切群。
