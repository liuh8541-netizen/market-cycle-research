# 0/1 主劇本樹模型設計

建立日：2026-09-03

## 核心定義

模型最後必須收斂成一個共通主劇本：

**1 = 通過目前階梯，進入下一階攻防。**

**0 = 未通過目前階梯，退回上一階重煉。**

所有複雜分析都要服務這個主劇本：八卦、兵法、K線、日夜盤、外部新聞、族群分化、散戶心理、法人籌碼、期貨、選擇權、程式模型誤差吸收，最後都必須回答同一件事：

**目前這一階，過不過？**

## 細胞分子式結構

0/1 是外層答案，但內部不能粗糙。每一個 0 或 1 底下都要繼續分化成可驗證組織：

| 層級 | 要回答的問題 | 常用證據 |
| --- | --- | --- |
| 價格層 | 是否破線、站回、收穩 | 開高低收、關鍵價、收盤位置 |
| 量能層 | 是換手、恐慌、還是承接失敗 | 成交量、放量殺、縮量守 |
| 族群層 | 是全面健康還是權值撐盤 | 上漲家數、等權報酬、電子/金融/中小型 |
| 期貨層 | 期貨是領先、落後、還是誘導 | 台指期日夜盤、期現差、未平倉 |
| 外部層 | 外部條件是否改變戰場 | 美股、費半、ADR、VIX、利率、油價、匯率、地緣政治 |
| 心理層 | 群眾是在追高、恐慌、猶豫或回補 | 開高追價失敗、破線恐慌、跌破後收回 |
| 程式層 | 不同模型是否正在互相校準 | 均線、突破、避險、套利、ETF申贖、造市波動率 |
| 八卦層 | 目前屬於哪個週期姿態 | 震起、巽行、離亢、坤滯、兌誘、乾頂、坎陷、艮止 |
| 兵法層 | 今日攻防是虛、實、誘、守或退 | 虛實測敵、先求不敗、攻其無備、兵貴勝不貴久 |

## 節點格式

每個主劇本節點都必須固定輸出：

| 欄位 | 說明 |
| --- | --- |
| 目前階梯 | 當前最重要的價格或狀態關卡 |
| 主劇本 | 守住/通過為 1；失守/不通過為 0 |
| 1 的條件 | 要進入下一階必須達成的條件 |
| 0 的條件 | 退回上一階或重煉的條件 |
| 1 的下一階 | 通過後下一個觀察關卡 |
| 0 的下一階 | 失敗後下一個防守或修正關卡 |
| 證據 | 已發生的價格、量能、族群、日夜盤、外部資料 |
| 反證 | 會推翻目前判讀的條件 |
| 風險值 | 對風控的加減權，不是投資命令 |
| 驗證時間 | 開盤30分鐘、午盤、13:15後、收盤、夜盤 |

## 階段共通點規格

每一個階段都必須先找出一個「共通點」。共通點不是結論，而是該階段所有力量都會共同測試的核心問題。

格式固定如下：

| 欄位 | 說明 |
| --- | --- |
| 階段名稱 | 目前正在走的市場階段 |
| 階段共通點 | 多方、空方、散戶、法人、期貨與程式都在測的同一件事 |
| 往上條件 | 形成 1 的條件，代表通過目前階梯 |
| 往下條件 | 形成 0 的條件，代表退回上一階重煉 |
| 往上形成原因 | 為什麼會往上：承接、回補、利多、族群擴散、外部順風等 |
| 往下形成原因 | 為什麼會往下：賣壓、停損、追價退潮、外部利空、族群退潮等 |
| 往上走向 | 通過後的下一階攻防路線 |
| 往下走向 | 失敗後的下一階防守或退守路線 |
| 驗證資料 | 價格、量能、族群、期貨、外部、心理、程式、八卦、兵法 |

## 階段共通點範例

| 階段 | 共通點 | 往上條件 | 往下條件 | 往上原因 | 往下原因 | 往上走向 | 往下走向 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 測底防線 | 防線是否有真承接 | 守住或跌破後收回 | 跌破且收不回 | 低接、回補、恐慌被吸收 | 停損、多殺多、承接不足 | 回攻前一階 | 退守下一防線 |
| 收復前沿 | 失守區能否重新取回 | 收盤站回並守穩 | 反彈無力、收不回 | 買盤擴散、空方壓測失敗 | 上方套牢賣壓、追價退潮 | 轉攻下一壓力 | 回測主防線 |
| 攻擊權確認 | 是否有資格進攻主關卡 | 站上壓力且量價健康 | 攻上後壓回 | 趨勢資金加碼、族群同步 | 假突破、獲利了結 | 進入主攻段 | 延長賽整理 |
| 主攻關卡 | 是否突破大壓力區 | 放量站穩並維持高低點墊高 | 爆量不漲或長上影 | 主線基本面與資金共振 | 心理關卡賣壓、外部逆風 | 開啟新區間 | 打回重煉 |
| 高檔換手 | 風險是否仍可控 | 跌不破、收得回、族群輪動健康 | 跌破關鍵線且廣度惡化 | 籌碼換手成功、成本墊高 | 出貨擴散、程式停損連鎖 | 再攻或橫盤蓄勢 | 進入回測/修正 |

## 模型治理

- 0/1 主劇本是決策樹，不是買賣命令。
- 1 不是保證上漲，0 也不是保證崩盤；它們只代表階梯通過或失敗。
- 每個節點必須有明確驗證時間，不得事後回填。
- 每次失準要回到節點內部，找是哪一層判斷錯：價格、量能、族群、期貨、外部、心理、程式、八卦或兵法。
- 未經前瞻驗證的新增節點，只能列為研究候選，不得升級為正式交易訊號。
